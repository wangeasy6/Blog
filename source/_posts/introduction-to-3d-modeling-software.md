## 主要建模原理

### 多边形建模 (Polygon Modeling)

这是目前地球上**应用最广、受众最多**的建模方式。你在游戏中看到的角色、电影里的飞船、大部分动画主角，底层的网格都是多边形。

- **核心原理**：**“搭积木”与“切土豆”**。 一切始于一个简单的几何体（如立方体、球体）。通过不断地**切割（Subdivide）**、**挤压（Extrude）**、**倒角（Bevel）**，把一个简单的形状慢慢打磨成复杂的模型。它主要由点（Vertex）、线（Edge）、面（Polygon）组成，最终构成了一个“网格（Mesh）”。
- **优点**：极其灵活，硬件兼容性最好，所有的游戏引擎和渲染器都原生支持。
- **缺点**：如果要做极其圆滑、高精度的曲面（比如汽车漆面、人脸皮肤），需要极高的布线技巧和超多的面数，操作起来像是在走钢丝。
- **代表软件**： **Blender、Maya、3ds Max、Cinema 4D**：这些都是多边形建模的绝对主力。几乎所有主流3D软件都将多边形建模作为其核心功能。

### NURBS / 曲面建模 (Surface Modeling)

这是工业设计、汽车设计和高端珠宝设计的“御用”原理。如果你看到某个模型有着完美反光的流线型车身，那它极大概率是用这个原理做出的。

- **核心原理**：**“拉橡皮筋”与“套数学公式”**。 NURBS（Non-Uniform Rational B-Splines，非均匀有理B样条）不靠大量的面来近似形状，而是靠严谨的数学方程来定义曲线和曲面。你只需要画出几条控制线，软件就会自动计算出中间无比平滑的过渡面。
- **优点**：**精度极高，曲面无限光滑**。无论你怎么放大，边缘都不会有锯齿或棱角。
- **缺点**：很难用它来做有机生物（比如带皱纹的老头或者张牙舞爪的怪物），拓扑结构一旦复杂就容易出错。
- **代表软件**： **Rhino (犀牛)**：NURBS 建模的性价比之王，广泛应用于工业设计和建筑找形。 **Autodesk Alias**：汽车设计界的霸主，法拉利和特斯拉的设计师们就用它。 **SolidWorks / CATIA**：传统机械工程制图软件，也基于类似的精确曲面/实体原理。

### 数字雕刻 (Digital Sculpting)

当传统的“拉点扯线”无法满足艺术家对细节的狂热追求时，雕刻建模就诞生了。它彻底抛弃了严谨的网格布线。

- **核心原理**：**“捏橡皮泥”与“推面团”**。 就像现实中的雕塑家面对一块泥巴一样，你手里拿着一个数字刻刀，可以推、拉、捏、刮。它的底层虽然也是几百万个多边形，但软件会自动在后台处理拓扑，让使用者专注于形状和纹理本身。
- **优点**：**细节表现力无可匹敌**。毛孔、鳞片、布料褶皱，只有你想不到，没有它雕不出。
- **缺点**：雕刻出的模型面数极高（几千万面），绝不能直接塞进游戏引擎里跑，通常需要后期拓扑（Retopology）减面。
- **代表软件**： **ZBrush**：雕刻界的泰斗，几乎垄断了次世代游戏和影视的高模制作。 **Blender (雕刻模式)**：近年来迎头赶上，依托免费开源，雕刻功能已足够强大。 **Mudbox**：Autodesk推出的雕刻软件，可与Maya无缝协作。

### 体素与分形建模 (Voxel & Fractal Modeling)

这是一种完全不同于“表面”建模的原理，它关注的是物体的“体积”本身。

- **核心原理**：**“玩我的世界”与“种珊瑚”**。 体素（Voxel）可以理解为三维空间里的像素点。你不再是塑造外壳，而是像玩《我的世界》一样，在三维网格里填充或挖空方块。而分形算法则可以通过简单的数学公式，递归生成极其复杂的自然地貌（如山脉、河流、树枝）。
- **优点**：极其适合制作硬表面的破损、孔洞、以及复杂的自然环境，不需要考虑拓扑和法线方向。
- **缺点**：难以制作规整的、硬边缘的机械或建筑。
- **代表软件**： **Houdini**：VFX（视觉特效）领域的王者，极度依赖程序化和分形算法来生成城市崩塌、龙卷风等大规模特效。 **3D Coat**：一款强大的体素雕刻软件，常用于游戏贴图绘制和硬表面辅助建模。 **MagicaVoxel**：轻量级免费的体素建模工具，风靡独立游戏圈。

### 程序化建模 (Procedural Modeling)

这是“懒人”的终极福音，也是高阶特效师的杀手锏。你不需要动手去捏每一个细节，而是告诉软件“规则”，让它自己生成。

- **核心原理**：**“写菜谱”与“连电路”**。 通过节点网络（Node-based）或编写代码，设定一系列参数和逻辑关系。比如：“在一根线上每隔10厘米生成一个叶片，叶片的大小随机在1-3厘米之间。”只要你改变参数，整个模型就会自动重新生成。
- **优点**：**修改成本极低，无限可调，极其擅长制作重复度高的复杂结构**（如毛发、植被、城市建筑群）。
- **缺点**：学习曲线极其陡峭，需要有较强的逻辑思维能力。
- **代表软件**： 
  - **OpenSCAD**：用于创建实体三维 CAD 的开源免费软件，简单易用，3D 打印的最佳拍档。
  - **Houdini**：程序化建模的巅峰，好莱坞大片的特效流水线核心。
  - **Blender (Geometry Nodes)**：Blender近年来的超级杀招，通过节点连线实现了强大的程序化场景搭建。 
  - **Cinema 4D (MoGraph)**：虽然偏向运动图形，但其核心逻辑也是基于程序化克隆和效果器。
  - **Grasshopper (Rhino插件)**：参数化建筑的代名词，拖拽连线即可生成复杂表皮。

## 常见软件

以下按软件的主要建模原理分组；同组中，开源软件排在前面。部分软件支持多种建模方式，这里按其主要特点归类。

## 多边形网格建模

### [Blender](https://www.blender.org/)

* **Slogan**：覆盖完整 3D 创作流程的免费开源软件。
* **软件性质**：免费、开源（[GNU GPL](https://www.blender.org/about/license/)）软件。由 Blender 基金会协调社区开发，主要资金来源于捐赠。
* **支持平台**：Windows（x86/ARM）、macOS、Linux、Steam、Source Code
* **建模原理**：多边形建模、数字雕刻、程序化建模（Geometry Nodes）等。
* **适用领域**：动画、游戏资产、影视视觉特效、渲染、3D 打印和通用 3D 创作。

### [ZBrush](https://www.maxon.net/zh/zbrush)

* **Slogan**：使用虚拟黏土塑造角色、生物和精彩世界。
* **软件性质**：[Maxon](https://www.maxon.net/en/) 推出的商业软件，按月/年付费授权（[方案与定价](https://www.maxon.net/zh/buy)）。
* **支持平台**：Windows（x86/ARM）、macOS、iPadOS、Linux
* **建模原理**：以数字雕刻和高密度多边形网格为主，也支持传统多边形建模。
* **适用领域**：影视和游戏角色、高精度生物与道具模型、概念雕刻及 3D 打印。

### [Cinema 4D  (C4D)](https://www.maxon.net/zh/cinema-4d)

* **Slogan**：面向动态设计与三维内容制作的创作工具。
* **软件性质**：Maxon 商业软件，采用付费授权。
* **支持平台**：Windows、macOS
* **建模原理**：多边形建模、参数化建模及程序化克隆（MoGraph）等。
* **适用领域**：动态设计、广告、电视与电影包装、动画、产品可视化和通用三维内容制作。

### [Autodesk Maya](https://www.autodesk.com.cn/products/maya/overview)

* **Slogan**：创建规模宏大的世界、复杂的角色和炫酷的特效。
* **软件性质**：Autodesk 推出的商业软件，按月/年付费订阅授权或使用[Flex](https://www.autodesk.com.cn/buying/flex?term=100&tab=flex&plc=FLEXACCESS)购买代币后灵活支付。
* **支持平台**：Windows、macOS、Linux
* **建模原理**：以多边形建模为主，并提供曲面建模、动画、绑定和动力学模拟工具。
* **适用领域**：影视动画、角色动画、游戏资产制作和视觉特效。

### [Autodesk 3ds Max](https://www.autodesk.com/products/3ds-max/overview)

* **Slogan**：创建沉浸式的世界和高质量的设计。
* **软件性质**：Autodesk 推出的商业软件，按月/年付费订阅授权或使用[Flex](https://www.autodesk.com.cn/buying/flex?term=100&tab=flex&plc=FLEXACCESS)购买代币后灵活支付。
* **支持平台**：Windows
* **建模原理**：以多边形建模为主，支持样条线、修改器堆栈和程序化建模。
* **适用领域**：建筑可视化、室内设计、游戏资产、动画和视觉特效。

## NURBS 曲线与曲面建模

## 常见的 3D 文件格式

不同软件的原生文件通常最适合在原软件中继续编辑；需要在不同软件间传递模型时，常用中性 CAD 格式或网格格式。导入、导出能力会因软件版本、授权和工作区而异，交换格式也可能无法保留原有的建模历史、约束或全部材质效果。

### 原生工程文件

原生格式通常可以保留软件特有的参数、图层、节点、装配或编辑历史，但一般不适合作为跨软件交换格式。

| 格式 | 常见软件 | 说明 |
| --- | --- | --- |
| `.blend` | Blender | 保存场景、模型、材质、动画和节点等 Blender 项目数据。 |
| `.ma`、`.mb` | Maya | Maya 场景文件；`.ma` 为文本格式，`.mb` 为二进制格式。 |
| `.max` | 3ds Max | 3ds Max 场景文件，适合在该软件中继续编辑。 |
| `.ztl`、`.zpr` | ZBrush | ZBrush 工程格式，可保存雕刻模型及相应项目数据。 |
| `.c4d` | Cinema 4D | 保存 Cinema 4D 场景、对象和动画等内容。 |
| `.3dm` | Rhino | Rhino 的原生格式，也可保存曲线、曲面和实体等几何数据。 |
| `.FCStd` | FreeCAD | FreeCAD 文档格式，适合保留参数化模型及特征树。 |
| `.f3d`、`.f3z` | Fusion | Fusion 设计文件；`.f3z` 常用于打包包含外部引用的设计。 |
| `.sldprt`、`.sldasm` | SOLIDWORKS | 分别用于零件和装配体；关联文件和版本会影响打开与引用。 |
| `.prt`、`.asm` | Creo、Siemens NX | 分别常用于零件和装配体。不同软件可能使用相同扩展名，但文件并不因此兼容。 |
| `.CATPart`、`.CATProduct` | CATIA | 分别用于零件和产品装配。 |
| `.hip` | Houdini | Houdini 场景工程文件，可保存节点网络、场景和相关设置。 |
| `.skp` | SketchUp | SketchUp 模型文件，便于在 SketchUp 中继续编辑。 |
| `.scad` | OpenSCAD | 文本脚本源文件，保存构造模型的代码和参数。 |
| `.dwg` | AutoCAD | AutoCAD 原生绘图格式，可包含二维图形和三维 CAD 数据。 |

### CAD 交换格式

这类格式主要用于在 CAD 软件之间传递精确几何。通常能交换实体或曲面，但未必保留原软件中的特征树、草图约束、装配关系或完整设计意图。

| 格式 | 常见用途与支持软件 |
| --- | --- |
| `.step`、`.stp` | 通用 CAD 交换格式，适合在 Fusion、FreeCAD、SOLIDWORKS、Creo、NX、CATIA、Shapr3D 等软件间传递零件和装配几何。通常优先于 STL 用于机械零件交换。 |
| `.iges`、`.igs` | 较早期的 CAD 交换格式，常用于曲线和曲面数据交换；许多 CAD 软件仍提供支持。 |
| `.x_t`、`.x_b` | Parasolid 几何交换格式，适合支持 Parasolid 的 CAD 软件之间传递实体和曲面。 |
| `.sat` | ACIS 几何交换格式，可用于支持 ACIS 的 CAD 软件间交换实体和曲面。 |
| `.3mf` | 面向增材制造的格式，可包含单位、颜色和材质等信息；适合支持该格式的建模软件与切片软件之间传递打印模型。 |

### 多边形网格与 3D 打印格式

网格格式通常将模型表示为三角形或多边形表面，适合雕刻、动画、实时渲染和打印；它们一般不包含 CAD 特征历史。

| 格式 | 常见用途与支持软件 |
| --- | --- |
| `.stl` | 3D 打印中非常常见，只保存三角网格表面，不保存单位、材质或颜色等信息。导出和切片时应确认尺寸单位及模型是否封闭。Blender、ZBrush、Fusion、FreeCAD、Shapr3D、Tinkercad、OpenSCAD 等常用于生成或导出 STL。 |
| `.obj` | 通用网格交换格式，可保存几何、法线和 UV；材质通常放在配套的 `.mtl` 文件中。常用于 Blender、Maya、3ds Max、ZBrush、Cinema 4D 等软件间传递静态模型。 |
| `.fbx` | 常用于动画和游戏制作，可交换网格、骨骼、动画及部分材质数据；不同软件之间的材质和动画效果可能存在差异。常见于 Maya、3ds Max、Blender 和 Cinema 4D 工作流。 |
| `.glb`、`.gltf` | 面向实时 3D 和网页展示的格式，可保存模型、材质、贴图及动画等数据；`.glb` 通常将数据打包为单个二进制文件。 |
| `.ply` | 常用于扫描数据、点云和网格交换，可按格式变体保存顶点颜色等属性；具体属性支持取决于软件。 |

### 动画缓存与场景交换格式

| 格式 | 常见用途与支持软件 |
| --- | --- |
| `.abc`（Alembic） | 用于在影视流程中传递烘焙后的动画几何缓存，常见于 Maya、Houdini、Blender、3ds Max 和 Cinema 4D。通常不用于保留可编辑的建模历史或绑定控制器。 |
| `.usd`、`.usda`、`.usdc`、`.usdz` | 用于组织和交换复杂 3D 场景，可包含层级、几何、动画及材质等数据。常见于 Blender、Maya、Houdini、3ds Max 等支持 USD 的工作流；各软件支持的版本和功能范围可能不同。 |
| `.bgeo`、`.bgeo.sc` | Houdini 几何缓存格式，适合 Houdini 程序化流程中的中间数据保存和交换。 |

### 二维图纸格式

虽然不是 3D 模型格式，但工程软件常将三维模型投影为二维图纸后导出：

| 格式 | 常见用途与支持软件 |
| --- | --- |
| `.dwg` | AutoCAD 常用的二维和三维绘图格式，也用于 CAD 图纸交换。 |
| `.dxf` | 常见的二维 CAD 交换格式，适合在 AutoCAD、Fusion、FreeCAD 等软件之间传递图形和工程图；对三维实体的支持因软件而异。 |
| `.pdf` | 用于发布和查看工程图的文档格式，便于打印和分享，但通常不能像 CAD 源文件一样编辑模型。 |

## 常见工作流

其实，在现代专业的3D生产流程中，大神们往往是**“多管齐下”**的。以下是几个常见的工作流：

**机械零件与产品设计**

1. 在 **Fusion、SolidWorks 或 FreeCAD** 中绘制带尺寸约束的草图，并通过拉伸、旋转、倒角等特征建立参数化模型。
2. 设计装配体，检查零件之间的干涉，并根据需要修改尺寸和特征。
3. 加工或跨 CAD 软件协作时，通常导出 **STEP**；进行 3D 打印时，则导出 **3MF 或 STL**，再放入切片软件设置打印参数并生成打印文件。

**建筑与室内效果图**

1. 根据平面图和尺寸，在 **SketchUp、3ds Max 或 Blender** 中搭建建筑空间、墙体、门窗和家具模型。
2. 为模型设置材质、灯光和相机；需要更丰富的家具或装饰细节时，也可以从资源库导入模型。
3. 使用 **Blender、3ds Max** 等软件及其渲染工具输出效果图或动画，并根据画面反馈调整模型、材质和灯光。

**次世代游戏角色设计**

1. 先用 **ZBrush（雕刻）** 捏出角色的身体和大致轮廓。
2. 导入 **Maya/Blender（多边形）** 重新拓扑出一个低面数的模型（为了游戏性能）。
3. 将高模的细节烘焙（Bake）成法线贴图，贴在低模上。
4. 如果有飘逸的长发，可能会用到 **Blender的头发粒子系统（程序化）** 或者插件。
